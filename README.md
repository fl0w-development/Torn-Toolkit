# Torn Toolkit — Combat Edition

I built Torn Toolkit to make keeping up with targets, chains, and wars a little easier. Everything is in one place, right inside Torn, whether you're playing on your PC or using Torn PDA.

It's a tool to help you stay organized, **not an auto-attacker**. You still decide who to hit and when.

## What It Does

- **Targets** — Save players to your list, organize them into groups, leave notes, check their status, and jump straight to their attack page.
- **Solo Chain** — Set up your own hit list, change the order, and skip targets when you need to.
- **Faction Chain** — Put together a chain order, share it with your faction, or load an order someone else sent you.
- **War** — Look through faction rosters, search for players, and get to their attack pages without digging around.
- **Activity Tracker** — Track up to 10 players and see their usual online and offline hours from saved activity checks. There's a summary under each player's profile, too.
- **Aurora Theme** — A clean night-sky interface that fits right into Torn.

Your lists and settings are saved so you don't have to set everything up again every time.

## How to Install

**[Get the latest Torn Toolkit script](https://raw.githubusercontent.com/fl0w-development/Torn-Toolkit/main/torn-toolkit.user.js)**

### Torn PDA (iPhone / Android)

1. Open **Torn PDA → Settings → User Scripts**.
2. Add a new script and paste in the code from the link above.
3. Set the injection time to **END** and enable it.
4. Reload Torn. The Toolkit should show up in the page.

Torn PDA can use the API key you've already configured in the app.

### PC / Browser

1. Install **Tampermonkey** or **Violentmonkey**.
2. Open the script link above and install it in your userscript manager.
3. Open the Toolkit's **Settings** tab in Torn and enter your Torn API key.

**Already have it installed?** Update your existing script instead of adding another copy. That way you don't end up with two Toolkits running.
